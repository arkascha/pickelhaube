Version History

What changed in each version of Pickelhaube, the newest first. Inside the app, Settings › What’s new shows the notes of the version you have.

1.12.0 November 18, 2026

  • The helmet joins in: puzzled, searching or checking its list in messages and questions, hopping along as you dial, cheering when the other side answers
  • On Android 12 and newer the helmet wobbles as the app starts; on older Android the app wears its own colours – the blue and brass of the helmet
  • Names like FRITZ!Box are no longer split at the end of a line, and the titles of dialogs are centred

1.12.0 on GitHub

1.11.0 November 17, 2026

  • Called more than once in a row? Recent shows how often after the name – “Mum (3)”
  • A question mark beside “Hang up on the device itself”, and a link in connection errors, lead to the answers on the web page
  • Better with screen readers and large text: switches say what they switch, the call status is read out, Recent no longer cuts off names and numbers

1.11.0 on GitHub

1.10.1 November 16, 2026

  • Feedback welcome: Settings has a link to the feedback form on the web page – for a problem, an idea or a word of praise

1.10.1 on GitHub

1.10.0 November 14, 2026

  • “Call via FRITZ!Box” in your phone's contacts app: switch it on in the settings, and a row beside each number opens it in Pickelhaube
  • Away from home? When no FRITZ!Box answers, the dialer says why – a tap shows what helps: Wi-Fi at home, or a VPN into your home network

1.10.0 on GitHub

1.9.0 November 14, 2026

  • Fix a typo in the middle of a number: tap right after it, ⌫ and the keys work there
  • Busy or not answered? “Try again” calls once more
  • Numbers grouped everywhere: lists, suggestions, call status
  • “Copy number” in the long-press menu
  • The box not answering for a moment: a short note with “try again”, no message in the way
  • Speed dials: the free slots folded into one row

1.9.0 on GitHub

1.8.0 November 13, 2026

  • Recent calls by day, and a filter for the missed ones
  • A call button on every number in the lists
  • The number in groups, with whose it is; with the field empty, the green button brings back the last number
  • Removed a speed dial by mistake? Undo
  • Turned sideways or on a tablet: the keypad beside the rest
  • Back from the dialer leads to the list you picked from
  • Fixed: quick taps that slid a little on a key got lost

1.8.0 on GitHub

1.7.0 November 12, 2026

  • Pull the dialer down to read everything from your FRITZ!Box again
  • The helmet joins in: beside your box's name in the dialer, acting out your calls, and in empty lists
  • Optional key tones, and keys that spring back with a light vibration
  • Fixed: phone books changed on the FRITZ!Box itself got in the way of speed dials and handing over contacts
  • Fixed: taps while the app was talking to the box were lost

1.7.0 on GitHub

1.6.2 November 12, 2026

  • Fixed: a speed dial whose entry was deleted in the FRITZ!Box web interface could no longer be changed or removed until the app was restarted – the app now reads the phone books again and carries out the change
  • Phone books are read again when the app comes back to the foreground
  • “What's new” in the settings names the version its notes belong to

1.6.2 on GitHub

1.6.1 November 11, 2026

  • Fixed: when the widget was placed before setting up a FRITZ!Box, the welcome tour could not connect – now the tour comes first and the widget's setup follows
  • Under the hood: the widget shows its list the way newer Android versions ask for, updated build tools, small corrections

1.6.1 on GitHub

1.6.0 November 9, 2026

  • Help one tap away: “Guide on the web” and the privacy policy at the bottom of the settings, and a (?) on every page of the welcome tour
  • After an update, a short note says once what is new – again any time under Settings › What's new
  • A livelier welcome tour

1.6.0 on GitHub

1.5.0 November 8, 2026

  • Welcome tour: on first start, a friendly guide leads step by step to the connection with your FRITZ!Box – it looks for the box, asks for user and password, and says which phone will ring. Again any time under Settings › Welcome tour
  • Choosing a user from the list no longer brings up the keyboard
  • Lighter placeholder texts in empty fields

1.5.0 on GitHub

1.4.0 November 7, 2026

  • Suggestions while typing: numbers and names from phone books and recent calls, also by the letters on the keys
  • Extensions and PINs after a pause (long-press *): dials the number, then says what to type
  • Internal calls between the FRITZ!Box' phones (switch on per box)
  • Several own numbers: “From <number>”, and shown in Recent
  • Warning when an internet number is not registered
  • Fix: the FRITZ!Box no longer stops answering over HTTPS
  • Language “Auto” shown as a globe

1.4.0 on GitHub

1.3.0 November 4, 2026

  • Home screen widget: your own list of numbers, in Pickelhaube's colours or transparent
  • New missed calls on the FRITZ!Box are counted and marked in Recent
  • Dial with hidden number: long press on the green button
  • Share a text to Pickelhaube or paste it: the phone number in it goes into the dialer
  • While connected, the dialer says to hang up on the device itself
  • The version is shown at the bottom of the settings

1.3.0 on GitHub

1.2.0 November 1, 2026

  • Several FRITZ!Boxes: saving a box from another network no longer logs in to the box of the current one – its password and certificate stay where they belong. Changes made while away can be saved unchecked
  • A box with only one user gets it filled in; the user list marks the chosen user and explains the one made by the box
  • Shorter connection page: explanations behind (?), device details folded
  • “Display name”: only a label in the app
  • Hints, findings and values look different

1.2.0 on GitHub

1.1.0 October 31, 2026

  • Try it without a FRITZ!Box: “Fill in the demo box” when adding a box
  • New app icon in blue, yellow, red and white
  • Texts switch right away when the language changes
  • Better wording in Spanish, French and Italian
  • Settings are no longer copied to a new phone – use Settings › Back up and transfer
  • The version for Google Play no longer reads the phone’s own call log – Google Play allows that only for the default phone app. The full version from GitHub still can; the FRITZ!Box’s recent calls are in both
  • Updated libraries, for stability and security

1.1.0 on GitHub

1.0.0 October 28, 2026

  • First release: calls through the FRITZ!Box’s dial help – the box rings one of its phones and, once picked up, dials the number
  • Several FRITZ!Boxes; the one of the current network is chosen automatically
  • Recent calls and phone books of the box, and of the phone if you like
  • Speed dials: your own 1–9 and the box’s 00–99, set up from the app
  • Call forwarding of the box switched on and off
  • Live call status from the box’s call monitor
  • Quick settings tiles and launcher shortcuts
  • HTTPS with the box’s certificate; the box user’s rights shown and respected
  • Settings export and import, passwords optionally under a passphrase
  • Seven languages: English, German, Dutch, French, Italian, Spanish and Polish

1.0.0 on GitHub
