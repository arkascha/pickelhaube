1. Prepare your FRITZ!Box

Three settings in the FRITZ!Box web interface (http://fritz.box):

  1. Allow access for applications Home Network › Network › Network Settings – this switches on TR-064, the interface the app uses.
  2. Use dial help Telephony › Calls › Dial Help.
  3. A user with telephony permission System › FRITZ!Box Users – use or create one. If you log in to the box with a password only, it still has an auto-generated user name (like fritz1234), shown on that page; the app needs it. For the call list, the user also needs the permission Voice messages, fax messages, FRITZ!App Fon and call list.

Menu names follow the German FRITZ!OS translated into English; your box may word them slightly differently.

2. First start

On first start, a short welcome tour takes you there step by step, accompanied by the app icon's helmet with eyes: it explains what the box needs (with a link to section 1), looks for the box at fritz.box, asks for a display name – left empty, the box' own name is taken – and for your user name and password, connects, and tells you which phone the box will ring when you dial. That is the box' own setting for dial help: the tour reads it and changes nothing, as changing it may need a confirmation on the box.

If the box rejects user name or password, the tour leads straight back to the password. All settings opens the full connection page described below, with your entries; Skip leads there too. Settings › Welcome tour starts the tour again, for example to add another box.

Moving from another phone? The tour's first page offers Restore backup… (see Backup). No FRITZ!Box at hand? Try the demo box › there connects a box built into the app – with phones, phone books, a call list and a simulated call – to look around.

On the connection page, enter the box's address (fritz.box or 192.168.178.1), the user name and the password. Once the address is entered, the user name field offers the users the box knows (choose with ▾) – handy for the auto-generated one.

Optionally switch on Use HTTPS; the app then uses the box's HTTPS port (see HTTPS). Without it, the password still never travels in clear text (digest authentication).

Save & connect tests the settings first and only saves them once the router accepts them. If something is wrong – user name, password, missing permission, wrong port, router not reachable – a dialog explains it.

The connection page offers the demo box as well (No FRITZ!Box? Try the demo box at its top), and, while no box is set up yet, Restore backup….

Each connection has its own switches: Phone books, Call list and Speed dials (on by default), and Internal calls (off by default, see Internal calls).

3. Dialling

  1. Choose the phone that should ring In Ring phone, pick your DECT handset (or another phone the box knows).
  2. Enter a number Long-press 0 for +, or choose one from the phone books or recent calls. If you like the beep of a phone's keypad, switch on Key tones in the settings (off by default).
  3. Tap the green button Your handset rings. Pick it up – the box now dials the number.

The number is shown in groups, as numbers are written (030 1234567), and once it is in one of your phone books or recent calls, the name above it says whose it is – also when you typed it in full. With nothing entered, the green button brings back the number you dialled last; tap it once more to dial.

Pull the dialer down to read everything from your FRITZ!Box again – after changing something there, or switching networks.

Turned sideways – a phone or a tablet – the keypad moves to the right and the number, the phone that rings and the buttons to the left; on a phone, the green and red buttons stand beside the keys. On a tablet held upright the dialer keeps a phone's width, with larger keys.

While a call is under way, the green button is off for its number – dialling it again would only ring your phone again. The red button cancels a call that is still being set up. Once the call is connected, end it on the handset: the box cannot hang up a connected call for you.

A long press on the green button offers more:

  • Hide my number – your own number is withheld for this call (the box' code *31#).
  • From … – with several internet numbers on the box, the call goes out over the one you choose instead of the one set up for your handset.

Extensions, PINs and phone menus

Digits to type once the call is connected – an extension, a conference PIN, a choice in a phone menu – follow the number after a pause: long-press * for a ,, as in 0301234567,42#. The box' dial help cannot send such digits as tones, so Pickelhaube dials only the number and tells you what to type: below the dialer before the call, and in bold once it is connected (Now type 42# on the phone, with the live call status). Numbers from contacts or links bring their extension along (x 42, ;ext=42).

Numbers from elsewhere

Pickelhaube handles tel: links, so you can choose it when tapping a number in Contacts or on a web page. You can also share a text to Pickelhaube – an email signature, a message – or paste one with the paste button of the empty number field: the phone number in it is picked out and cleaned for dialling (+49 (0)30 / 123 45-6 becomes +4930123456); with several, the app asks which one.

Notes on the dialer

Above the buttons, the dialer points out what needs a look: an internet number of the box that is not registered with its provider (calls over it fail – a tap checks again), and new missed calls on the box since you last looked at Recent – a tap on that line shows just the missed calls; the address-book button shows their count as well.

4. Choosing a number

The address-book button left of the number field opens Choose number:

  • Recent – numbers recently dialled, received or missed, from the FRITZ!Box call list (including calls made on the handsets themselves). Each number appears once, at its latest call, under the day it was on (Today, Yesterday, the weekday, then the date). The filter at the top right of the list (a funnel with the missed-call arrow) shows just the numbers whose latest call was missed.
  • Phone books – the phone books stored on the box, including online books it syncs (e.g. CardDAV). Search by name or number. Optionally, your phone's own contacts appear as an extra book This phone (off by default; the app asks once).
  • Speed dial – see below.

Tapping a number puts it into the dialer; its green call button calls it right away – in the recent calls, the speed dials, the phone books and the box' own phones. Back right after that leads to the list again, where you left it – handy to pick another one.

In Recent, new missed calls are marked, and with several own numbers on the box each call says which one it was on (from 030 123456, to Office).

Suggestions while typing: from the third key on, the row below the number field offers the numbers from the phone books and recent calls that what you type may be heading for – numbers starting with it (however they are written), and names whose letters are on the keys you typed (2766 finds Arno). A tap takes the best one; 3 more ▾ opens the others.

Long-press a number for more: Add to this phone's contacts, Hand over to the FRITZ!Box (copies a phone contact into one of the box's phone books), and making it a speed dial.

Numbers written differently (+49 30 123456, 030 123456, 123456) are recognised as the same, using the country and area code set on your box. The number dialled is always exactly the one entered.

5. Speed dial

  • This phone: 1–9 – stored on the phone, valid with every box. Long-press the digit in the dialer; digits with a speed dial show a small dot.
  • FRITZ!Box: 00–99 – the speed dials from the box's phone books, the same ones the handsets use with **7. Tap the first digit and long-press the second, or type **7 and the number. While the box is reachable, you can also set, replace and remove them from the app. Entries changed on the box in the meantime (e.g. deleted in its web interface) are picked up: the app reads the phone books again when it comes back to the foreground, and when the box refuses a change for that reason.

Removing a speed dial, or deleting a copy the app made on the box, happens right away – a note at the bottom says so, with Undo to put it back.

6. Internal calls

With several phones on the box, Pickelhaube can call one from another – the kitchen from the study, for free. Switch on Internal calls on the box' connection page; Choose number then has a tab Internal with the box' phones and their internal numbers: analogue phones (**1, **2), DECT handsets (**610 to **615), IP phones and FRITZ!App Fon (**620 …), and All phones (**9). Their names are found in the suggestions while typing too.

The phone under Ring phone rings first and then calls the other one, so choose a single phone there – a group would ring the called phone as well. A phone cannot call itself; Pickelhaube says so instead of dialling.

7. Several FRITZ!Boxes

Settings › FRITZ!Box connections holds any number of boxes – home, office, parents – each with its own address, user, password and options. The box of the current network is chosen automatically: at start, when the network changes, and when the app comes back to the foreground – or right away when you pull the dialer down. The dialer's title shows the box in use, beside the helmet. A box reachable only through a VPN or MyFRITZ is used when the local network has none of yours.

To make sure it really is your box, Pickelhaube checks the box's device id and serial number, and refuses a box whose number differs from the stored one. Each connection page also shows the model, FRITZ!OS version and the permissions of the configured user.

8. Live call status

Above the buttons, the dialer shows how the call goes: pick up, calling …, connected with a timer, and finally call ended with its duration (or not answered). The helmet beside it acts the call out – it rings, listens, nods, and waves goodbye.

This uses the box's call monitor, which is off by default. Switch it on once by dialling #96*5* on a phone connected to the box (#96*4* switches it off).

The call monitor needs no login and is not encrypted: while it is on, any device in your home network can follow the box's calls, numbers included. Without it, Pickelhaube works as well – it just shows pick up.

Internal calls are not followed yet: it is not known whether the call monitor reports them.

9. Call forwarding

The forwarding symbol in the dialer's top bar lists the call forwardings set up on the box, each with a switch. The box only allows switching them on and off through the app; set them up on the box itself (Telephony › Call Handling › Call Forwarding).

10. Tiles, shortcuts and widget

Three quick settings tiles: Pickelhaube (opens the dialer, shows whether a box is reachable), Redial (opens the dialer with the last number – you still press the green button) and Call forwarding. From Android 13 on, Settings › Quick settings tiles adds them for you.

A long press on the app icon offers Redial (dials right away), Call forwarding, Dial number, and which FRITZ!Box is reachable from here.

The home screen widget Numbers to dial holds numbers you choose, each widget its own list with an optional title, in Pickelhaube's colours or transparent. Set it up when placing it (add numbers from the number picker, reorder, remove); the Pickelhaube icon in its corner opens the setup again. A tap on an entry puts its number into the dialer – it is dialled only with the green button.

11. HTTPS and the router certificate

The FRITZ!Box uses a self-signed certificate. Pickelhaube uses trust on first use: on the first HTTPS connection it shows the certificate's fingerprints. Compare them with what your browser shows for https://fritz.box, then tap Trust. From then on only that certificate is accepted; if the box ever presents a different one, you get a Certificate has changed! warning instead of a silent connection.

12. Confirmation on the box

Newer FRITZ!OS versions ask for an additional confirmation for settings changes. Changing which phone rings for dial help is such a change; dialling itself is not. When needed, a dialog tells you what to do – press a button on the box or dial a shown code – and the app continues automatically.

13. Backup and transfer

Settings › Back up and transfer exports all connections and options to a JSON file and imports them again. Passwords are included only if you ask for it, then encrypted with a passphrase of your choice.

14. Language

English, German, Dutch, French, Italian, Spanish and Polish – automatic (the system language, shown as a globe 🌐) or chosen with the flag button in the settings. The translations still need a review by native speakers; corrections are very welcome.

Help, updates and the web page

The (?) in the top bar of the welcome tour opens the part of this guide that goes with its page. At the bottom of the settings, below the version, are What's new, Guide on the web and Privacy policy. After an update, Pickelhaube shows once what is new for you – a few points, over the dialer; What's new shows them again. The web pages are in English.

16. Limitations

  • Works only while the phone is in the home network of the box, or connected to it through a VPN.
  • Google Play allows the call log permission only for the default phone app. The option to include the phone's own calls under Recent therefore works only when Pickelhaube is installed from outside Google Play.
  • Call forwardings can be switched on and off, not set up.
  • The box' dial help only dials: it sends no tones once connected (see extensions) and cannot end a connected call.
  • The box knows only one phone for dial help, and changing it needs a confirmation on newer FRITZ!OS – so there is no way to let another phone ring for a single call.
