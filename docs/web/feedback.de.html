Feedback

Etwas funktioniert nicht, eine Idee, eine Frage oder einfach ein Lob – ich lese jede Nachricht.

Bitte gib keine Kennwörter ein und keine Namen und Nummern aus deinen Telefonbüchern. Was mit dem Gesendeten geschieht, steht in der Datenschutzerklärung.

Das Formular selbst ist auf Englisch – schreib gern auf Deutsch.

Fehlerberichte sind auch als Issues auf GitHub willkommen.
